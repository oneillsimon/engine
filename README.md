# engine

A small C++20 3D engine core: GLFW/OpenGL4 windowing, an entity/component
tree, GLSL program management, and a Lua scripting layer built with SWIG.

## Building

Requires CMake 3.16+, a C++20 compiler, Lua 5.4 and Python 3 with Jinja2
(e.g. `apt install liblua5.4-dev python3-jinja2`). All other dependencies
(GLFW, GLM, stb, googletest and the generated GLAD loader) are fetched or
generated by the build.

```
cmake -B build
cmake --build build
```

GLAD is generated at configure time for OpenGL 4.5 core with glad2
(https://github.com/Dav1dde/glad).

## Tests

```
cmake --build build --target engine-tests
ctest --test-dir build
```

Coverage build (GCC/Clang only):

```
cmake -B build -DENGINE_ENABLE_COVERAGE=ON
cmake --build build --target engine-tests
ctest --test-dir build
```

## Lua scripting

The SWIG bindings expose the engine to Lua: applications, entities and
components can be defined in script with `initialise`/`update`/`render`
callbacks that the engine invokes each frame. `example.lua` at the repo
root is a small self-contained example; the `engine-exe` target runs it.

## Structure

- `src/` - engine core (engine loop, entities/components, input, windowing,
  GLSL programs, lights, meshes, scripting helpers)
- `swig/` - SWIG interface files generating the Lua bindings
- `applications/` - OpenGL Shading Language Cookbook sample applications
  (chapters 1-2), integrated as `Application` subclasses
- `tests/` - gtest suite
- `extern/` - build dependencies (fetched or generated at configure time)
